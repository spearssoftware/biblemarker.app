If you use BibleMarker on a computer — Mac, Windows, or Linux — a few keys can save you some mouse trips. Every shortcut here is completely optional: everything in the app can also be reached by mouse or touch, so if you'd rather not memorize anything, you don't have to. (On an iPad, these work too if you have a keyboard attached.)

| Keys | What it does |
|------|--------------|
| **←** / **→** | Previous / next chapter |
| **J** / **K** | Next / previous chapter — like flipping pages |
| **Cmd+F** (Mac) or **Ctrl+F** (Windows/Linux) | Open Search |
| **1** | Open **Key Words** |
| **2** | Open **Observe** |
| **3** | Open **Analyze** |
| **4** | Open **Study Tools** |
| **Esc** | Close whatever panel or window is open |

A couple of notes:

- **Settings** has no number key — just click the **Settings** (⚙️) button at the bottom right of the screen.
- If a shortcut doesn't seem to work, you're probably typing in a note or a text box. Click somewhere on the Bible text first, then try again. (**Esc** always works, even while typing.)
